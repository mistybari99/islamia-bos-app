নতুন SQL (ধাপ ১৫–১৭) — ৩টি ট্যাপ

এতে কোনো গোপন তথ্য নেই: শুধু নতুন টেবিল, নিয়ম আর ফাংশন। কাজ শেষ হলে এই পাতা মুছে দেওয়া হবে।
১. প্রথমে এই বোতাম চাপুন (পুরো SQL কপি হবে)
২. তারপর Supabase খুলুন → বাঁ দিকে SQL Editor → New query → লেখার ঘরে চেপে ধরে Paste ২. Supabase SQL Editor খুলুন ৩. সবুজ Run চাপুন। "Success. No rows returned" এলে হয়ে গেল।

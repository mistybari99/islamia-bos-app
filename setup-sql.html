একবারের SQL (সেল, ছবি, ব্যবসার হিসাব)

এতে কোনো গোপন তথ্য নেই। শুধু টেবিল আর হিসাবের ফাংশন যোগ হয়। কাজ শেষ হলে এই পাতা মুছে দেওয়া হবে।
ধাপ ১
নিচের বোতাম চাপুন। Supabase খুলবে আর SQL নিজে থেকে বসে থাকবে। (লগইন চাইলে লগইন করুন।) ১. Supabase এ SQL খুলুন ধাপ ২
Supabase-এ সবুজ Run বোতাম চাপুন। "Success" এলে হয়ে গেল।
যদি SQL নিজে না বসে: নিচের বোতামে কপি করে, Supabase এর SQL Editor-এ New query খুলে পেস্ট করুন, তারপর Run।

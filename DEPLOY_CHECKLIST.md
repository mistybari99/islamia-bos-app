## How phones get the new version (no stale mix)
- `index.html` now loads every script and style as `file?v=a70e358993`. A phone that still holds an old `app.js` in its cache asks for a different address, so old JS can never run with the new `index.html`.
- `sw.js` VERSION is `bos-sw-a70e358993`. The file changed, so the browser installs it, and on activation it deletes every older `bos-sw-*` cache. The service worker is network first, so an online phone gets the new files at once; offline phones keep the last cached set.
- GitHub Pages may serve the old `index.html` for up to about 10 minutes after the push. During that time a phone gets a complete old set (old index with old scripts), never a mix.
- A phone with the PWA open: close and reopen the app once (or pull to refresh). Nothing needs to be cleared by hand.
